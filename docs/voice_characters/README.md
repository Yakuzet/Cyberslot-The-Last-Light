## Recording

Use the same format as the hostess sheet:

| Setting | Value |
|---|---|
| File type | `.wav` (best). `.ogg` or `.mp3` also work |
| Channels | Mono |
| Sample rate | 44,100 Hz or 48,000 Hz |
| Bit depth | 16-bit (for WAV) |
| File name | lowercase, exactly as listed, for example `frebby_1.wav` |
| Silence | Trim to almost nothing at the start; leave about 0.2 s at the end |
| Level | Peaks around -3 dB, same loudness across all files |
| One line per file | Yes |

The lines are taken word for word from the game. The game does not play character voices yet. They will be wired in once recordings exist.
